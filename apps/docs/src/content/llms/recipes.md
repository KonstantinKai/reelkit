# Recipes

Guides + API pages = one piece at a time. Recipe = start from feature to ship, combine pieces. Each recipe: live demo, full code per framework (React, Vue, Angular), why each part there.

- [Infinite Feed](https://reelkit.dev/docs/recipes/infinite-feed): load next page near end; loading + error slides, cancelled requests, preloaded media.
- [Grid to Player](https://reelkit.dev/docs/recipes/grid-to-player): open full-screen reel player from thumbnail grid; return viewer to last watched item.
- [Gallery Slideshow](https://reelkit.dev/docs/recipes/gallery-slideshow): lightbox gallery plays as slideshow; download original file per photo.
- [Stories Tray](https://reelkit.dev/docs/recipes/stories-tray): open stories player from ring row; remember seen stories across reloads.
