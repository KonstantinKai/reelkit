## ब्राउज़र में चलने वाले agents (WebMCP) [#webmcp]

reelkit.dev का हर पेज [WebMCP](https://webmachinelearning.github.io/webmcp/) tools रजिस्टर करता है, ताकि आपके ब्राउज़र में चल रहा AI agent रेंडर हुए पेज को scrape करने के बजाय docs सीधे पढ़ सके।

| Tool | काम |
| --- | --- |
| `list_pages` | हर docs पेज, उसके title, URL और group के साथ। |
| `search_docs` | `query` से साइट सर्च, वैकल्पिक `locale` और `framework` के साथ। अधिकतम 20 नतीजे, section anchors सहित। |
| `get_page` | एक पेज markdown में: वही अंग्रेज़ी टेक्स्ट जो `llms-full.txt` में उस पेज के लिए है। |
| `open_page` | पेज को मौजूदा टैब में, आप जिस भाषा में पढ़ रहे हैं उसी में खोलता है, चाहें तो किसी section पर। |

<Callout type="info">
  WebMCP अभी एक draft standard है। reelkit.dev पर यह origin trial के ज़रिए Chrome 149 से 156 में काम करता है; बाकी जगह Chrome में `chrome://flags/#enable-webmcp-testing` चालू करना होता है। जिन ब्राउज़र में यह नहीं है वे कुछ भी अतिरिक्त लोड नहीं करते। ये tools सिर्फ़ सार्वजनिक docs पढ़ते हैं: न cookies, न storage, न इस साइट के बाहर कोई request।
</Callout>

## क्या इंडेक्स होता है [#what-gets-indexed]

- शुरुआत + इंस्टॉलेशन
- Core इंजन गाइड + API
- React, Vue, Angular bindings (गाइड + API + reel-player + lightbox + stories-player)
- Stories core इंजन
- SSR नोट्स
- समस्या निवारण
- बदलावों की सूची

## क्यों? [#why]

AI असिस्टेंट लाइब्रेरी के बदलावों से पीछे रह जाते हैं। बनाया गया कोड पुराने API का हवाला देता है। ये endpoints डॉक्स की हर रिलीज़ के साथ अपडेट होते हैं, इसलिए सुझाव पिछली तिमाही के नहीं, मौजूदा व्यवहार से मेल खाते हैं।
