## क्या इंडेक्स होता है [#what-gets-indexed]

- शुरुआत + इंस्टॉलेशन
- Core इंजन गाइड + API
- React, Vue, Angular bindings (गाइड + API + reel-player + lightbox + stories-player)
- Stories core इंजन
- SSR नोट्स
- समस्या निवारण
- बदलावों की सूची

## क्यों? [#why]

AI असिस्टेंट लाइब्रेरी के बदलावों से पीछे रह जाते हैं। बनाया गया कोड पुराने API का हवाला देता है। ये endpoints डॉक्स की हर रिलीज़ के साथ अपडेट होते हैं, इसलिए सुझाव पिछली तिमाही के नहीं, मौजूदा व्यवहार से मेल खाते हैं।
