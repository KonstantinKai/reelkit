Angular के लिए फ़ुलस्क्रीन, Instagram जैसा stories प्लेयर overlay, जिसमें nested नेविगेशन, अपने-आप आगे बढ़ने वाला टाइमर, टैप ज़ोन और कस्टमाइज़ होने वाले template slots हैं।

<Callout type="info" title="जल्द आ रहा है">
  Angular stories प्लेयर पर अभी काम चल रहा है। React वाला रूप [@reelkit/react-stories-player](/docs/stories-player) पर अभी उपलब्ध है। Angular वाला रूप भी वही आर्किटेक्चर अपनाएगा, और फ़्रेमवर्क से स्वतंत्र state machine, टाइमर और canvas प्रोग्रेस renderer के लिए `@reelkit/stories-core` इस्तेमाल करेगा।
</Callout>
