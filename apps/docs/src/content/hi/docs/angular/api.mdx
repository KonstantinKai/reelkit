## BodyLockService [#bodylockservice]

## SoundStateService [#soundstateservice]

media चलाने वाले overlay की muted और disabled स्थिति, Angular signals के रूप में। इसे root पर नहीं, बल्कि उस component पर provide करें जिसके पास media है — तब हर overlay अपनी अलग स्थिति रखता है। reelkit का हर Angular overlay यही सेवा इस्तेमाल करता है — `@reelkit/angular-reel-player` भी वही class दोबारा export करता है, इसलिए वहाँ से किया गया पुराना import वैसे ही चलता रहता है।

lightbox अपवाद है: सेवा को `<rk-lightbox-overlay>` के **ऊपर** provide करें, क्योंकि उसका video slide आपके अपने template से render होता है और overlay के भीतर बने instance को कभी नहीं देख पाएगा।

<CodeBlock code={soundstateservice} language="typescript" />

| सदस्य | टाइप | विवरण |
| --- | --- | --- |
| `muted()` | `Signal<boolean>` | अभी आवाज़ बंद है या नहीं। शुरुआत muted से होती है |
| `disabled()` | `Signal<boolean>` | जब तक आवाज़ पर नियंत्रण संभव नहीं, तब तक true और sound button छिपा रहता है। इसे overlay तय करता है — `RkReelPlayerOverlayComponent` इसे तब उठाता है जब slide में वीडियो न हो या वह बदल रहा हो |
| `controller` | `SoundController (getter)` | नीचे मौजूद core का `SoundController` — इसे `syncMutedToVideo` को दें ताकि `<video>` muted स्थिति के साथ चलता रहे |
| `toggle()` | `() => void` | muted स्थिति बदलता है |

## createOverlayUrlState [#createoverlayurlstate]

<Signature>OverlayUrlStateOptions</Signature>

किसी overlay के लिए URL-स्टेट कंट्रोलर बनाता है, जिसे आप `<rk-lightbox-url-overlay>` को उसके `[controller]` input के रूप में देते हैं। इसे injection context में कॉल करें — field initialiser या constructor में; यह तुरंत जुड़ता है और `DestroyRef` से छूटता है। पूरी जानकारी: [Angular Lightbox पेज पर URL स्टेट](/docs/angular-lightbox#url-state)।

| विकल्प | टाइप | डिफ़ॉल्ट | विवरण |
| --- | --- | --- | --- |
| `param` | `string` | `required` | सक्रिय स्लाइड रखने वाला query parameter, जैसे photo। |
| `adapter` | `UrlAdapter` | `History API` | पढ़ने और लिखने के लिए नेविगेशन सिस्टम। routing वाले ऐप में Router पर आधारित adapter पास करें, ताकि Router की location पुरानी न पड़े। |
| `codec` | `UrlCodec<Id>` | `required` | wire का रूप: parameter के टेक्स्ट से स्थिर पहचान तक। मेल खाती जोड़ी के रूप में locator के साथ चलता है — डिफ़ॉल्ट ?photo=3 गैलरी के लिए ...urlIndexKey(() => images().length) spread करें, या अपना दें ताकि क्रम बदलने पर भी bookmark काम करे। |
| `locator` | `UrlLocator<Id>` | `required` | पहचान को स्थिति से जोड़ता है और उसकी वैधता खुद संभालता है: locate (sync), locateAsync (पेज वाली गैलरी के लिए async विकल्प), identify (writes)। |

## createRouterUrlAdapter [#createrouterurladapter]

<Signature>@reelkit/angular/ng-router-url-adapter</Signature>

Angular Router पर आधारित `UrlAdapter`। routing वाले ऐप में इसे `createOverlayUrlState` के `adapter` विकल्प के रूप में पास करें, ताकि नेविगेशन की सच्चाई का अकेला स्रोत Router ही रहे — Router के पीछे `history.pushState` लिखने से उसकी location पुरानी पड़ जाती है और उसका अगला नेविगेशन parameter गिरा देता है। Writes सिर्फ़ query को छूते हैं, इसलिए path, fragment और `?tag=a&tag=b` जैसी दोहराई गई keys बिना बदले साथ चलती हैं। हर बदलाव बताता है कि Router ने उसी पेज पर push किया, replace किया या history में आगे-पीछे गया, इसलिए `routerLink` से खुली गैलरी back के एक कदम से बंद होती है। इसे injection context में कॉल करें; router की subscription `DestroyRef` से छूटती है।

यह अपने अलग subpath से आता है, इसलिए बिना routing वाला ऐप `@angular/router` को कभी अपने बंडल में नहीं खींचता। `@angular/router` एक वैकल्पिक peer dependency है।

## सुलभता [#accessibility]

`<rk-reel>` `aria-roledescription="carousel"` के साथ `role="region"` के रूप में रेंडर होता है। क्षेत्र को स्क्रीन रीडर के लिए नाम देने के लिए `ariaLabel` input सेट करें। एक polite live region हर स्लाइड बदलने पर "Slide N of M" बोलता है। निष्क्रिय स्लाइडों को `inert` attribute मिलता है, ताकि फ़ोकस और सहायक तकनीक का नेविगेशन उन्हें छोड़ दे।

`<rk-reel-indicator>` बिंदुओं पर roving tabindex के साथ `role="tablist"` के रूप में रेंडर होता है; तीर वाली कुंजियाँ फ़ोकस खिसकाती हैं और Enter या Space स्लाइड सक्रिय करता है।

`<rk-reel>` के आसपास अपना modal बना रहे हैं? फ़ोकस लौटाने और रोकने के लिए `captureFocusForReturn`, `createFocusTrap` और `getFocusableElements` `@reelkit/angular` से भी export होते हैं।
