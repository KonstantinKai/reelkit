Full-screen, Instagram-style stories player overlay for Vue with nested navigation, auto-advance timer, tap zones, and customizable slots.

<Callout type="info" title="Coming Soon">
  The Vue stories player is currently in development. The React version is available now at [@reelkit/react-stories-player](/docs/stories-player). The Vue version will follow the same architecture, using `@reelkit/stories-core` for the framework-agnostic state machine, timer, and canvas progress renderer.
