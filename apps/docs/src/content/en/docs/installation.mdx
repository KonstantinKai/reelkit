### Comparison with Other Libraries [#comparison-with-other-libraries]

ReelKit renders **3 slides to DOM** at any time and handles 10,000+ items. Other carousel libraries render all slides, which stalls on large lists.

## Peer Dependencies [#peer-dependencies]

Framework packages have peer dependencies that should already be in your project:

<FrameworkVariant for="react">

### @reelkit/react [#reelkit-react]

- `react` >= 18.0.0
- `react-dom` >= 18.0.0

### @reelkit/react-reel-player [#reelkit-react-reel-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-lightbox [#reelkit-react-lightbox]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-stories-player [#reelkit-react-stories-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="angular">

### @reelkit/angular [#reelkit-angular]

- `@angular/core` >= 17.0.0
- `@angular/common` >= 17.0.0

### @reelkit/angular-reel-player [#reelkit-angular-reel-player]

- `@reelkit/angular`
- `@angular/core` >= 19.0.0
- `lucide-angular` >= 0.460.0

### @reelkit/angular-lightbox [#reelkit-angular-lightbox]

- `@reelkit/angular`
- `@angular/core` >= 17.0.0
- `lucide-angular` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="vue">

### @reelkit/vue [#reelkit-vue]

- `vue` >= 3.0.0

</FrameworkVariant>
