Full-screen, Instagram-style stories player overlay for Angular with nested navigation, auto-advance timer, tap zones, and customizable template slots.

<Callout type="info" title="Coming Soon">
  The Angular stories player is currently in development. The React version is available now at [@reelkit/react-stories-player](/docs/stories-player). The Angular version will follow the same architecture, using `@reelkit/stories-core` for the framework-agnostic state machine, timer, and canvas progress renderer.
</Callout>
