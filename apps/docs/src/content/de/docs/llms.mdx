## Endpunkte [#endpoints]

| Endpunkt | Wofür |
| --- | --- |
| [`/llms.txt`](https://reelkit.dev/llms.txt) | Indexierte Liste der Links zu jeder Seite der Dokumentation. Füge sie in den Kontext eines beliebigen LLM ein. |
| [`/llms-full.txt`](https://reelkit.dev/llms-full.txt) | Derselbe Index, ergänzt um die Zusammenfassung jeder Seite. Der vollständige Korpus mit einer einzigen Anfrage. |
| [`context7.com/websites/reelkit_dev`](https://context7.com/websites/reelkit_dev) | Live indexiertes Manifest von Context7. Binde es über den MCP-Server @context7 ein. |

## Agenten im Browser (WebMCP) [#webmcp]

Jede Seite auf reelkit.dev registriert [WebMCP](https://webmachinelearning.github.io/webmcp/)-Tools. Ein KI-Agent, der in deinem Browser läuft, liest die Dokumentation also direkt, statt die gerenderte Seite auszulesen.

| Tool | Wofür |
| --- | --- |
| `list_pages` | Jede Seite der Dokumentation mit Titel, URL und Gruppe. |
| `search_docs` | Die Suche der Website über `query`, optional mit `locale` und `framework`. Bis zu 20 Treffer, Anker der Abschnitte inklusive. |
| `get_page` | Eine Seite als Markdown: der englische Text, den `llms-full.txt` für sie enthält. |
| `open_page` | Öffnet eine Seite im aktuellen Tab, in der Sprache, in der du gerade liest, auf Wunsch an einem bestimmten Abschnitt. |

<Callout type="info">
  WebMCP ist ein Entwurf für einen Standard. Auf reelkit.dev funktioniert es in Chrome 149 bis 156 über einen Origin Trial; anderswo braucht Chrome `chrome://flags/#enable-webmcp-testing`. Browser ohne WebMCP laden nichts zusätzlich. Die Tools lesen nur die öffentliche Dokumentation: keine Cookies, kein Speicher, keine Anfragen an andere Websites.
</Callout>

## Warum? [#why]

KI-Assistenten hinken Änderungen an Bibliotheken hinterher. Generierter Code verweist auf veraltete APIs. Diese Endpunkte werden mit jedem Release der Dokumentation aktualisiert, sodass die Vorschläge zum aktuellen Verhalten passen und nicht zu dem des letzten Quartals.
