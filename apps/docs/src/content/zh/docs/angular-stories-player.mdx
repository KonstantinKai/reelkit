title: Angular Stories Player
description: Angular Stories 播放浮层：进度、手势与主题定制。
---

面向 Angular 的全屏 Instagram 风格 Stories 播放浮层，支持嵌套导航、自动播放计时、点击区域和可定制模板插槽。

<Callout type="info" title="即将推出">
  Angular 版 Stories Player仍在开发中。React 版现已可用： [@reelkit/react-stories-player](/docs/stories-player)。Angular 版会沿用同样的架构，用 `@reelkit/stories-core` 作为与框架无关的状态机、计时器和 canvas 进度渲染器。
</Callout>
