### 与其他库的对比 [#comparison-with-other-libraries]

ReelKit 任何时候只往 DOM 里渲染 **3 张幻灯片**，可以扛住 10,000+ 条目。其他轮播库会渲染全部幻灯片，列表一大就卡。

## 同级依赖 [#peer-dependencies]

框架相关的包都有同级依赖，通常你的项目里已经装好了：

<FrameworkVariant for="react">

### @reelkit/react [#reelkit-react]

- `react` >= 18.0.0
- `react-dom` >= 18.0.0

### @reelkit/react-reel-player [#reelkit-react-reel-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-lightbox [#reelkit-react-lightbox]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-stories-player [#reelkit-react-stories-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="angular">

### @reelkit/angular [#reelkit-angular]

- `@angular/core` >= 17.0.0
- `@angular/common` >= 17.0.0

### @reelkit/angular-reel-player [#reelkit-angular-reel-player]

- `@reelkit/angular`
- `@angular/core` >= 19.0.0
- `lucide-angular` >= 0.460.0

### @reelkit/angular-lightbox [#reelkit-angular-lightbox]

- `@reelkit/angular`
- `@angular/core` >= 17.0.0
- `lucide-angular` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="vue">

### @reelkit/vue [#reelkit-vue]

- `vue` >= 3.0.0

</FrameworkVariant>

<FrameworkVariant for="react">

<Callout type="info">
  `lucide-react` 只用于默认的控制图标。如果你通过 `renderControls` 提供自己的控件，就可以不装它。
</Callout>

</FrameworkVariant>

<FrameworkVariant for="angular">

<Callout type="info">
  `lucide-angular` 只用于默认的控制图标。如果你通过 `rkPlayerControls` 提供自己的控件，就可以不装它。
</Callout>

</FrameworkVariant>

## TypeScript [#typescript]
