## 端点 [#endpoints]

| 端点 | 用途 |
| --- | --- |
| [`/llms.txt`](https://reelkit.dev/llms.txt) | 每个文档页的索引链接列表。可直接放进任意大模型上下文。 |
| [`/llms-full.txt`](https://reelkit.dev/llms-full.txt) | 同样的索引，外加每页的内嵌摘要。一次请求拿到全部语料。 |
| [`context7.com/websites/reelkit_dev`](https://context7.com/websites/reelkit_dev) | 实时索引的 Context7 清单。通过 @context7 MCP 服务器接入。 |

## 为什么？ [#why]

AI 助手总是跟不上库的变化，生成的代码引用的是过时的 API。这些端点会随每次文档发布更新，因此建议贴合当前行为，而不是上个季度的。
