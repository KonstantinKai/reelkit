## 浏览器内的 Agent（WebMCP） [#webmcp]

reelkit.dev 的每个页面都会注册 [WebMCP](https://webmachinelearning.github.io/webmcp/) 工具，浏览器里运行的 AI Agent 可以直接读取文档，而不必抓取渲染后的页面。

| 工具 | 用途 |
| --- | --- |
| `list_pages` | 列出所有文档页面及其标题、URL 和分组。 |
| `search_docs` | 按 `query` 使用站内搜索，可选 `locale` 和 `framework`。最多 20 条结果，含章节锚点。 |
| `get_page` | 以 markdown 返回单个页面：即 `llms-full.txt` 中该页的英文内容。 |
| `open_page` | 在当前标签页中以你正在阅读的语言打开页面，可直接定位到某个章节。 |

<Callout type="info">
  WebMCP 仍是标准草案。在 reelkit.dev 上，它通过 origin trial 在 Chrome 149–156 中可用；在其他地方，Chrome 需开启 `chrome://flags/#enable-webmcp-testing`。不支持它的浏览器不会额外加载任何内容。这些工具只读取公开文档：不使用 cookie，不使用存储，也不会请求本站以外的地址。
</Callout>

## 为什么？ [#why]

AI 助手总是跟不上库的变化，生成的代码引用的是过时的 API。这些端点会随每次文档发布更新，因此建议贴合当前行为，而不是上个季度的。
