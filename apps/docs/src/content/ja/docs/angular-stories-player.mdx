Angular 用の、Instagram 風のフルスクリーンのストーリーのオーバーレイです。ネストしたナビゲーション、自動送りのタイマー、タップゾーン、カスタマイズできるテンプレートスロットを備えます。

<Callout type="info" title="近日公開">
  Angular 版のストーリープレイヤーは現在開発中です。React 版は [@reelkit/react-stories-player](/docs/stories-player) ですでに利用できます。Angular 版も同じアーキテクチャで、フレームワークに依存しない状態機械、タイマー、canvas の進捗レンダラーに `@reelkit/stories-core` を使う予定です。
</Callout>
