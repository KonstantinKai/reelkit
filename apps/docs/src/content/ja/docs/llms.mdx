## エンドポイント [#endpoints]

| エンドポイント | 用途 |
| --- | --- |
| [`/llms.txt`](https://reelkit.dev/llms.txt) | すべてのページへのリンクの索引です。どの LLM のコンテキストにもそのまま入れられます。 |
| [`/llms-full.txt`](https://reelkit.dev/llms-full.txt) | 同じ索引に、ページごとの要約を埋め込んだものです。1 回の取得でコーパス全体が手に入ります。 |

## ブラウザ内のエージェント（WebMCP） [#webmcp]

reelkit.dev のすべてのページは [WebMCP](https://webmachinelearning.github.io/webmcp/) ツールを登録します。ブラウザで動く AI エージェントは、描画済みのページをスクレイピングせずにドキュメントを直接読めます。

| ツール | 用途 |
| --- | --- |
| `list_pages` | すべてのドキュメントページをタイトル、URL、グループ付きで返します。 |
| `search_docs` | `query` によるサイト内検索。`locale` と `framework` は任意。最大 20 件で、セクションのアンカーも含みます。 |
| `get_page` | 1 ページを markdown で返します。`llms-full.txt` がそのページに収める英語のテキストです。 |
| `open_page` | 読んでいる言語のまま、現在のタブでページを開きます。セクションを指定することもできます。 |

<Callout type="info">
  WebMCP はまだ標準の草案です。reelkit.dev では origin trial により Chrome 149〜156 で動作します。それ以外のサイトでは Chrome に `chrome://flags/#enable-webmcp-testing` が必要です。対応していないブラウザは何も追加で読み込みません。ツールは公開ドキュメントを読むだけで、cookie もストレージも使わず、このサイト以外へのリクエストも行いません。
</Callout>

## なぜ？ [#why]

AI アシスタントはライブラリの変更に追いつくのが遅れがちです。生成されたコードは古い API を参照します。これらのエンドポイントはドキュメントの公開ごとに更新されるので、提案が前の四半期ではなく現在の挙動に沿ったものになります。
