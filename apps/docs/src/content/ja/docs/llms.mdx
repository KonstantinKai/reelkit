## エンドポイント [#endpoints]

| エンドポイント | 用途 |
| --- | --- |
| [`/llms.txt`](https://reelkit.dev/llms.txt) | すべてのページへのリンクの索引です。どの LLM のコンテキストにもそのまま入れられます。 |
| [`/llms-full.txt`](https://reelkit.dev/llms-full.txt) | 同じ索引に、ページごとの要約を埋め込んだものです。1 回の取得でコーパス全体が手に入ります。 |
| [`context7.com/websites/reelkit_dev`](https://context7.com/websites/reelkit_dev) | ライブで索引される Context7 のマニフェストです。@context7 MCP サーバー経由で接続します。 |

## なぜ？ [#why]

AI アシスタントはライブラリの変更に追いつくのが遅れがちです。生成されたコードは古い API を参照します。これらのエンドポイントはドキュメントの公開ごとに更新されるので、提案が前の四半期ではなく現在の挙動に沿ったものになります。
