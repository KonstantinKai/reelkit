Overlay de stories a pantalla completa al estilo de Instagram para Angular, con navegación anidada, temporizador de avance automático, zonas de toque y slots de plantilla personalizables.

<Callout type="info" title="Próximamente">
  El Stories Player para Angular está en desarrollo. La versión de React ya está disponible en [@reelkit/react-stories-player](/docs/stories-player). La versión de Angular seguirá la misma arquitectura y usará `@reelkit/stories-core` para la máquina de estados, el temporizador y el renderizador de progreso en canvas, independientes del framework.
</Callout>
