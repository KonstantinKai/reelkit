Overlay de stories a pantalla completa al estilo de Instagram para Vue, con navegación anidada, temporizador de avance automático, zonas de toque y slots personalizables.

<Callout type="info" title="Próximamente">
  El Stories Player para Vue está en desarrollo. La versión de React ya está disponible en [@reelkit/react-stories-player](/docs/stories-player). La versión de Vue seguirá la misma arquitectura y usará `@reelkit/stories-core` para la máquina de estados, el temporizador y el renderizador de progreso en canvas, independientes del framework.
</Callout>
