### Comparación con otras librerías [#comparison-with-other-libraries]

ReelKit renderiza **3 slides en el DOM** en todo momento y admite más de 10.000 elementos. Otras librerías de carrusel renderizan todos los slides, y eso se atasca con listas grandes.

## Peer dependencies [#peer-dependencies]

Los paquetes de cada framework tienen peer dependencies que tu proyecto ya debería incluir:

<FrameworkVariant for="react">

### @reelkit/react [#reelkit-react]

- `react` >= 18.0.0
- `react-dom` >= 18.0.0

### @reelkit/react-reel-player [#reelkit-react-reel-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-lightbox [#reelkit-react-lightbox]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-stories-player [#reelkit-react-stories-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="angular">

### @reelkit/angular [#reelkit-angular]

- `@angular/core` >= 17.0.0
- `@angular/common` >= 17.0.0

### @reelkit/angular-reel-player [#reelkit-angular-reel-player]

- `@reelkit/angular`
- `@angular/core` >= 19.0.0
- `lucide-angular` >= 0.460.0

### @reelkit/angular-lightbox [#reelkit-angular-lightbox]

- `@reelkit/angular`
- `@angular/core` >= 17.0.0
- `lucide-angular` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="vue">

### @reelkit/vue [#reelkit-vue]

- `vue` >= 3.0.0

</FrameworkVariant>

## TypeScript [#typescript]

Todos los paquetes incluyen definiciones de tipos de TypeScript. No hace falta instalar paquetes @types adicionales.
