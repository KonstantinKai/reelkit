## Контролер Stories [#stories-controller]

`createStoriesController(config, events?)` повертає `StoriesController`, який керує навігацією між групами та історіями. Стежить за станом паузи, запам’ятовує останню переглянуту історію в кожній групі й викликає колбеки на кожному переході.

### Конфігурація (StoriesControllerConfig) [#config-storiescontrollerconfig]

| Властивість | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `groupCount` | `number` | required | Загальна кількість груп історій |
| `storyCounts` | `number[]` | required | Кількість історій у кожній групі |
| `initialGroupIndex` | `number` | 0 | Початковий індекс групи |
| `initialStoryIndex` | `number` | resumeStoryIndex(initialGroupIndex), інакше 0 | Початковий індекс історії всередині групи. Явно названий переважає над збереженим; пропустіть — і початкова група відновлюється, як і всі інші. |
| `defaultImageDuration` | `number` | 5000 | Типова тривалість автопереходу для історій-зображень у мілісекундах |
| `resumeStoryIndex` | `(groupIndex: number) => number` | undefined | Історія, на якій відкривається ще не відвідана група; обмежена наявними історіями |

### Події (StoriesControllerEvents) [#events-storiescontrollerevents]

| Event | Тип | Опис |
| --- | --- | --- |
| `onStoryChange` | `(groupIndex, storyIndex) => void` | Спрацьовує, коли змінюється активна історія |
| `onGroupChange` | `(groupIndex) => void` | Спрацьовує, коли змінюється активна група |
| `onStoryViewed` | `(groupIndex, storyIndex) => void` | Спрацьовує, коли історія стає видимою |
| `onStoryComplete` | `(groupIndex, storyIndex) => void` | Спрацьовує, коли завершується таймер історії (перед переходом) |
| `onComplete` | `() => void` | Спрацьовує, коли завершується остання історія останньої групи |
| `onClose` | `() => void` | Спрацьовує, коли оверлей має закритися |

### Стан (реактивні сигнали) [#state-reactive-signals]

| Signal | Тип | Опис |
| --- | --- | --- |
| `state.activeGroupIndex` | `Signal<number>` | Індекс поточної активної групи |
| `state.activeStoryIndex` | `Signal<number>` | Індекс поточної активної історії всередині групи |
| `state.isPaused` | `Signal<boolean>` | Чи призупинено автоперехід |

### Методи [#methods]

| Метод | Тип | Опис |
| --- | --- | --- |
| `nextStory()` | `() => void` | Перехід уперед у межах групи; на межі переходить у наступну групу |
| `prevStory()` | `() => void` | Перехід назад у межах групи; на межі переходить у попередню групу |
| `nextGroup()` | `() => void` | Перемикає на наступну групу, продовжуючи з останньої переглянутої історії |
| `prevGroup()` | `() => void` | Перемикає на попередню групу, продовжуючи з останньої переглянутої історії |
| `goToGroup(index)` | `(number) => void` | Перехід до конкретної групи за індексом |
| `pause()` | `() => void` | Призупиняє автоперехід |
| `resume()` | `() => void` | Відновлює автоперехід |
| `onStoryTimerComplete()` | `() => void` | Викликається, коли таймер завершується; спрацьовує onStoryComplete, а потім відбувається перехід |
| `getLastStoryIndex(groupIndex)` | `(number) => number` | Де відкривається група: історія, на якій її залишили в цій сесії, інакше та, що назве resumeStoryIndex |
| `reportInitialView()` | `() => void` | Повідомляє історію, на якій відкрився плеєр, як переглянуту — один раз. Викликайте після монтування, а не під час рендерингу. |
| `updateConfig({ groupCount, storyCounts })` | `(config) => void` | Замінює кількість груп та історій, коли стрічка змінюється при відкритому плеєрі, щоб можна було перейти до груп, завантажених пізніше. Не надсилає жодної події, зберігає місце, де залишили кожну групу, і повертає позиції в межі стрічки, яка скоротилася. |

## Контролер таймера [#timer-controller]

`createTimerController(config)` керує автопереходом через цикл `requestAnimationFrame` . Сигнал прогресу (від 0 до 1) живить смугу прогресу. Пауза й відновлення зберігають точну позицію.

### Конфігурація (TimerControllerConfig) [#config-timercontrollerconfig]

| Властивість | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `duration` | `number` | required | Типова тривалість у мілісекундах |
| `onComplete` | `() => void` | undefined | Викликається, коли таймер доходить до 100% |

### State [#state]

| Signal | Тип | Опис |
| --- | --- | --- |
| `progress` | `Signal<number>` | Сигнал прогресу (від 0 до 1) |
| `isRunning` | `Signal<boolean>` | Чи таймер зараз працює |

### Методи [#methods]

| Метод | Тип | Опис |
| --- | --- | --- |
| `start(duration?)` | `(number?) => void` | Запускає (або перезапускає) таймер із необов’язковою заміною тривалості |
| `pause()` | `() => void` | Заморожує прогрес на поточній позиції |
| `resume()` | `() => void` | Продовжує із замороженої позиції |
| `reset()` | `() => void` | Скидає прогрес до 0 і зупиняє |
| `dispose()` | `() => void` | Звільняє ресурси |

## Рендерер прогресу на Canvas [#canvas-progress-renderer]

`createCanvasProgressRenderer(config?)` малює сегментовані смуги прогресу на canvas. Масштабується під дисплеї Retina, вимірює свій контейнер через ResizeObserver і вмикає рухоме вікно, коли сегменти не вміщаються.

### Config (CanvasProgressRendererConfig) [#config-canvasprogressrendererconfig]

| Властивість | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `gap` | `number` | 2 | Проміжок між сегментами в пікселях |
| `barHeight` | `number` | 2 | Висота смуги в пікселях |
| `minSegmentWidth` | `number` | 8 | Мінімальна ширина сегмента, після якої вмикається рухоме вікно |
| `bgColor` | `string` | 'rgba(255,255,255,0.3)' | Колір тла незаповнених сегментів |
| `fillColor` | `string` | '#ffffff' | Колір заповнення завершених та активних сегментів |

### Методи [#methods]

| Член | Тип | Опис |
| --- | --- | --- |
| `attach(canvas)` | `(HTMLCanvasElement) => void` | Підключає до елемента canvas; запускає ResizeObserver на батьківському елементі |
| `draw(totalStories, activeIndex, progress)` | `(number, number, number) => void` | Малює смугу прогресу для заданого стану |
| `width` | `number (readonly)` | Поточна виміряна ширина в пікселях CSS |
| `dispose()` | `() => void` | Прибирає ResizeObserver і внутрішній стан |

## Контролер переглянутого [#viewed-controller]

`createStoriesViewedStateController(config)` — це все, що потрібно стрічці, аби пам'ятати переглянуте, одним викликом: лічильники для кілець, місце, з якого відновлюється кожна група, і запис переглядів поверх сховища, яке переживає перезавантаження. Він не імпортує жодного фреймворку, тож React, Vue та Angular користуються ним однаково: створіть його один раз там, де живе стрічка, і передайте списку кілець та плеєру, які самі під'єднують його і стежать за ним. Він зібраний на `createViewedStateController` ядра з двовісним ключем за стабільними id; беріть їх напряму, коли це не підходить. Запис називає найдальшу досягнуту історію, а не підрахунок переглядів, тож місце групи переживає перевпорядкування стрічки, а вилучена із середини групи історія скорочує лічильник і знову засвічує кільце.

### Конфігурація (StoriesViewedStateControllerConfig) [#config-storiesviewedstatecontrollerconfig]

| Властивість | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `storageKey` | `string` | обов'язково | Ключ сховища, під яким записуються записи |
| `groups` | `() => StoriesGroup<T>[]` | обов'язково | Читає поточні групи. Це getter, він викликається щоразу, тож стрічці, яка довантажує групи, досить їх повертати. Тримайте його актуальним: getter, що застряг на першому масиві, неправильно рахує всі групи, завантажені пізніше. |
| `key` | `UrlKey<Id, TwoAxisPosition>` | стабільні id | Як позиція записується у сховищі. Передайте ключ, яким користується контролер URL, і запис читатиметься як посилання, яким поділилися. |
| `storage` | `StorageAdapter` | localStorage | Де зберігаються записи. Власний адаптер — це також спосіб під'єднати власне сховище переглянутого. |
| `ttlMs` | `number` | не спливає | Скільки запис групи пам'ятається після останнього запису. Кожна група спливає за власним годинником. |
| `maxTracks` | `number` | усі групи | Скільки груп зберігати. Понад це група, записана найдавніше, відкидається під час наступного запису. |

`storageKey`, `key` і `storage` читаються один раз, під час створення контролера. Щоб змінити сховище, створіть інший контролер.

### StoriesViewedStateController [#storiesviewedstatecontroller]

| Член | Тип | Опис |
| --- | --- | --- |
| `viewedState` | `Subscribable<Map<string, number>>` | Переглянуті історії за id автора, як сигнал. Порожній до attach(). |
| `controller` | `ViewedStateController<TwoAxisPosition>` | Сховище під ним, для всього, чого це не охоплює |
| `resumeStoryIndex(groupIndex)` | `(number) => number` | Перша непереглянута історія або 0, коли групу переглянуто до кінця |
| `markViewed(groupIndex, storyIndex)` | `(number, number) => void` | Записує історію як переглянуту. Плеєр викликає це для кожної показаної історії. |
| `forget()` | `() => void` | Забуває все переглянуте, тут і у сховищі |
| `attach()` | `() => Dispose` | Читає сховище і стежить за іншими вкладками. Веде лік, тож список кілець і плеєр можуть під'єднуватися та розмонтовуватися в будь-якому порядку. Компоненти плеєра викликають його самі. |

## Допоміжні функції розкладу [#layout-helpers]

Чисті функції, які плеєр кожної прив’язки поділяє з іншими, тож React, Vue й Angular рахують розміри та розкладку однаково. Їх викликає прив’язка; застосунку вони потрібні лише тоді, коли він будує власний плеєр.

### Розміри [#sizing]

| Функція | Тип | Опис |
| --- | --- | --- |
| `getStoriesSize()` | `() => [number, number]` | Розмір полотна історії. Телефон заповнює екран; десктоп заповнює висоту вікна мінус поле 16px у пропорції 9:16 і вужчає лише тоді, коли полотно й обидві стрілки не вміщаються поперек. Без вікна (рендеринг на сервері) повертає `[0, 0]`. |
| `isMobileWidth(viewportWidth)` | `(number) => boolean` | Чи користується вікно такої ширини розкладом для телефона. 768 і менше — телефон, як і в стилях. |
| `parseDurationMs(value)` | `(string) => number` | Найдовший час зі списку обчисленого `transition-duration`, у мілісекундах. Усе, що не є часом, рахується як нуль. |

### Геометрія десктопної каруселі [#desktop-carousel-geometry]

Зсуви рахують від активної групи: від’ємні ліворуч, додатні праворуч, `0` — сама активна історія.

| Функція | Тип | Опис |
| --- | --- | --- |
| `getCardSize(activeSize)` | `([number, number]) => [number, number]` | Розмір бічної картки: 0.4 висоти активної історії в тій самій пропорції 9:16. |
| `getCarouselSlot(offset, activeSize)` | `(number, [number, number]) => CarouselSlot` | Де стоїть картка відносно центру вікна: `{ x, width, height }`. Перша картка з кожного боку обходить стрілку, кожна наступна додає ширину картки й проміжок. |
| `getCardOffsets(activeGroupIndex, groupCount)` | `(number, number) => number[]` | Зсуви карток, намальованих навколо активної групи у спокої, до двох з боку, без самої активної. |
| `isCardShown(offset)` | `(number) => boolean` | Чи картка на такій відстані малюється, а не згасає. |
| `getSlotOffset(offset)` | `(number) => number` | Слот, до якого їде картка, обмежений на одне місце далі за показані, щоб картка в’їжджала збоку від останньої видимої. |
| `getSlideGroupIndexes(from, to, groupCount)` | `(number, number, number) => number[]` | Групи, які малює з’їзд між двома групами: картки навколо обох кінців, у порядку груп. Групи, через які перестрибує далекий перехід, пропускаються. |

### Вигляд [#presentation]

| Функція | Тип | Опис |
| --- | --- | --- |
| `getRingPresentation(options)` | `(RingPresentationOptions) => RingPresentation` | Клас, інлайн-стиль і розмір аватара кільця історії з `totalStories`, `viewedCount` і `size`. Якщо лишилося що дивитися — конічний градієнт, що обертається; додивлена група — рівний `viewedColor`; порожня — без кільця. Розміри несуть одиниці `px`, тож об’єкт стилю годиться для будь-якого фреймворку. |
| `kStoriesRingSize`, `kStoriesRingListRingSize`, `kStoriesCardRingSize` | `number` | Діаметри кілець, які кожна прив'язка малює за замовчуванням, у пікселях: 68 для окремого кільця, 64 у списку кілець, 52 на картці десктопної каруселі. Передайте одне як `size`, щоб збігтися з плеєрами. |
| `getPreviewSource(story)` | `(StoryItem \| undefined) => string \| undefined` | Зображення, яке показує картка каруселі: `poster` історії, сама картинка, якщо це зображення, і нічого для відео без постера. Картка без зображення повертається до простої картки, яку малюють для історії, що не має чого показати. |
| `formatTimeAgo(date)` | `(string \| Date) => string` | Короткий відносний час, який показують заголовок і картки каруселі: `now`, `5m`, `3h`, `2d`, `2w`. |

Поряд із ними експортовано типи `CarouselSlot`, `RingPresentation` і `RingPresentationOptions`.
