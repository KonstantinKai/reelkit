## Агенти в браузері (WebMCP) [#webmcp]

Кожна сторінка reelkit.dev реєструє інструменти [WebMCP](https://webmachinelearning.github.io/webmcp/), тож AI-агент у вашому браузері читає документацію напряму, а не розбирає відрендерену сторінку.

| Інструмент | Призначення |
| --- | --- |
| `list_pages` | Усі сторінки документації з назвою, URL і розділом. |
| `search_docs` | Пошук сайту за `query`, з необовʼязковими `locale` і `framework`. До 20 результатів, з якорями розділів. |
| `get_page` | Одна сторінка в markdown: англійський текст, який містить для неї `llms-full.txt`. |
| `open_page` | Відкриває сторінку в поточній вкладці мовою, якою ви читаєте, за потреби одразу на потрібному розділі. |

<Callout type="info">
  WebMCP — чернетка стандарту. На reelkit.dev він працює в Chrome 149–156 завдяки origin trial; деінде Chrome потребує прапорця `chrome://flags/#enable-webmcp-testing`. Браузери без нього нічого додатково не завантажують. Інструменти лише читають публічну документацію: без cookie, без сховища, без запитів за межі цього сайту.
</Callout>

- Прив’язки для React, Vue, Angular (посібник, API, reel-плеєр, Lightbox, плеєр історій)

## Навіщо? [#why]

AI-асистенти відстають від змін у бібліотеці, і згенерований код спирається на застарілі API. Ці точки доступу оновлюються з кожним випуском документації, тож підказки відповідають поточній поведінці, а не тій, що була минулого кварталу.
