## Точки доступу [#endpoints]

| Точка доступу | Призначення |
| --- | --- |
| [`/llms.txt`](https://reelkit.dev/llms.txt) | Індексований список посилань на кожну сторінку документації. Кидайте в контекст будь-якої мовної моделі. |
| [`/llms-full.txt`](https://reelkit.dev/llms-full.txt) | Той самий індекс плюс вбудовані підсумки кожної сторінки. Увесь корпус за один запит. |
| [`context7.com/websites/reelkit_dev`](https://context7.com/websites/reelkit_dev) | Маніфест Context7 із живим індексом. Підключається через MCP-сервер @context7. |

## Що потрапляє в індекс [#what-gets-indexed]

- Початок роботи та встановлення
- Посібник із рушія ядра та API
- Прив’язки для React, Vue, Angular (посібник, API, reel-плеєр, Lightbox, плеєр історій)
- Рушій Stories Core
- Нотатки про SSR
- Усунення несправностей
- Журнал змін

## Навіщо? [#why]

AI-асистенти відстають від змін у бібліотеці, і згенерований код спирається на застарілі API. Ці точки доступу оновлюються з кожним випуском документації, тож підказки відповідають поточній поведінці, а не тій, що була минулого кварталу.
