## Auto-sizing [#auto-sizing]

The `size` необов’язковий. Якщо його не передати, `<Reel>` сам вимірює свій контейнер через `ResizeObserver` і підлаштовується під макет, заданий CSS. Розмір контейнера має задавати батьківський елемент — наприклад, flex, grid або явні розміри в CSS.

## Стан в URL [#url-state]

`useOverlayUrlState` будує контролер стану в URL для оверлея й повертає його цілком, а ви передаєте його в `<LightboxUrlOverlay>` як його `:controller` . Стан відкриття належить адресному рядку, тож прив’язаний оверлей відкривається сам, а посилання — звичайний спосіб його відкрити. Перший запис відсутнього параметра додає один запис в історію, кожен наступний його замінює, тож гортання ніколи не ховає кнопку «назад». Тримайте контролер, щоб читати `value`/`позицією` і закривати програмно через `set(null)`, the same low-level write the overlay uses internally on slide change.

<CodeBlock code={urlState} language="vue" />

Об’єкт опцій приймає `param`, `codec`, та `locator` (усі три обов’язкові) плюс необов’язковий `adapter`. The `codec` та `locator` — узгоджена пара з однаковим `Id`, so for a plain `?photo=3` галереї розгортайте `...urlIndexKey(() => props.images.length)`, який повертає обидві половини одразу. `urlIndexKey` зіставляє параметр з індексом слайда й обмежує його живою кількістю, яку повертає геттер, тож застарілий або позамежний `?photo=99` відхиляється й сам зникає з URL замість того, щоб відкрити слайд, якого ніхто не називав. Передавайте геттер, а не число: у Vue `setup` виконується один раз, тож захоплена довжина застаріла б, поки посторінкова стрічка росте. Він загортає `createIndexLocator` (половину-локатор) і поєднує його з `indexCodec`. Посторінкова стрічка або галерея з адресацією за ідентичністю передає власну узгоджену пару `codec` + `locator` . Повна таблиця опцій — у [довіднику API для Vue](/docs/vue/api#useoverlayurlstate).

## Головне [#key-points]

<KeyPoints>
<KeyPoint title="Composition API">
  Import `Reel`, `ReelIndicator`, and composables directly into your `<script setup>` — реєструвати плагін не потрібно
</KeyPoint>
<KeyPoint title="слот #item з областю видимості">
  Відповідник у Vue для пропса `itemBuilder` із React — дає віртуалізацію звичним синтаксисом шаблонів
</KeyPoint>
<KeyPoint title="Шаблонний ref">
  Використовуйте `ref<ReelExpose>()` для імперативної навігації — колбеки подій не потрібні
</KeyPoint>
<KeyPoint title="@after-change">
  Emits `(index, rangeIndex)` — стежить за поточним індексом для оновлення інтерфейсу
</KeyPoint>
<KeyPoint title="контекст provide/inject">
  `ReelIndicator` сам під’єднується до батьківського `Reel` через provide/inject у Vue — жодного протягування пропсів вручну
</KeyPoint>
</KeyPoints>

## Поради щодо продуктивності [#performance-tips]

<KeyPoints>
<KeyPoint title="Тримайте шаблони слайдів легкими">
  The `#item` виконується для кожного видимого слайда (зазвичай трьох одночасно). Уникайте важких обчислень і глибоко вкладених структур усередині.
</KeyPoint>
<KeyPoint title="Вантажте дані ближче до краю">
  Використовуйте `@after-change` щоб помітити наближення до кінця й підвантажити наступний пакет, доки слайди не скінчилися — так виходить нескінченна стрічка.
</KeyPoint>
<KeyPoint title="Тримайте імперативний стан у ref">
  Зберігайте посилання `ReelExpose` та поточний індекс у `ref()`Vue — це дає точкову реактивність без зайвих перерендерів.
</KeyPoint>
<KeyPoint title="Вимикайте колесо на сторінках із прокручуванням">
  Set `:enable-wheel="false"` коли слайдер вбудований у макет із прокручуванням, щоб не перехоплювати прокручування сторінки.
</KeyPoint>
</KeyPoints>
