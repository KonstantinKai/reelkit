### Observe [#observe]

Містить між сигналами ядра й рендерингом React без зайвих рендерів батька. Коли підписані сигнали змінюються, виконується заново лише функція children.

<CodeBlock code={observe} language="tsx" />

| Prop | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `signals` | `Subscribable[]` | `required` | Сигнали для підписки. Сповіщення від будь-якого з них перезапускає функцію children — і лише її, ніколи батьківський компонент. Інший сигнал, переданий у пізнішому рендері, відстежується замість того, який він замінив. |
| `children` | `() => ReactElement \| null` | `required` | Функція рендерингу, що виконується заново на кожну зміну. Читайте значення сигналів усередині неї; прочитане ззовні захоплюється один раз і застаріває. |

### useOverlayUrlState [#useoverlayurlstate]

<Caption>`OverlayUrlStateOptions`</Caption>

Будує контролер стану в URL для оверлея, який ви передаєте в `*UrlOverlay` як його `controller` prop.

See [Стан в URL у посібнику для React](/docs/react/guide#url-state) — там покроковий розбір і приклади.

| Option | Тип | Типове значення | Опис |
| --- | --- | --- | --- |
| `param` | `string` | required | Параметр запиту, що несе активний слайд, наприклад "photo". Читається під час першого рендеру й не змінюється весь час життя компонента — щоб змінити, перемонтуйте його (задайте key). |
| `adapter` | `UrlAdapter` | History API | Система навігації, через яку читати й писати. У застосунку з роутером передайте адаптер на його базі, щоб власне місцеположення роутера не застаріло. Читається під час першого рендеру й не змінюється весь час життя компонента — щоб змінити, перемонтуйте його. |
| `codec` | `{ decode(raw) => Id \| null; encode(id) => string }` | required | Формат передавання: текст параметра ↔ стабільна ідентичність, незалежно від колекції. Іде разом із локатором як узгоджена пара з однаковим Id — розгорніть ...urlIndexKey(() => images.length) для типової галереї з ?photo=3 або передайте власний (base64, slug), щоб закладка пережила зміну порядку галереї. Читається наживо: наступне декодування чи кодування виконує кодек з останнього рендеру. |
| `locator` | `{ locate(id) => number \| null; locateAsync?(id) => Promise<number \| null>; identify(index) => id }` | required | Зіставляє ідентичність із позицією і сам відповідає за свою чинність: locate (синхронно), locateAsync (запасний варіант для посторінкової галереї), identify (для запису). Для звичайної галереї за індексом розгорніть ...urlIndexKey(() => images.length) — він дає цей локатор разом із відповідним кодеком і обмежує ?photo=3 живою кількістю, тож застарілий ?photo=99 сам зникає з URL замість того, щоб відкрити слайд, якого ніхто не називав. Посторінкова стрічка або галерея з адресацією за ідентичністю передає власну узгоджену пару кодек + локатор. Читається наживо: на наступний пошук відповідає локатор з останнього рендеру, а додавання чи прибирання locateAsync між рендерами діє з наступного промаху. |

### useReactRouterUrlAdapter [#usereactrouterurladapter]

A `UrlAdapter` на базі React Router. Передайте його як опцію `adapter` у `useOverlayUrlState` у застосунку з роутером, щоб роутер лишався єдиним джерелом правди про навігацію: запис `history.pushState` повз роутер лишає його місцеположення застарілим, і наступна навігація втрачає параметр. Запис торкається лише запиту, тож шлях і хеш лишаються недоторканими. Кожна зміна повідомляє, чи роутер додав запис на тій самій сторінці, замінив його чи пройшов історією, тож галерея, відкрита з `<Link>`, закривається одним кроком назад.

Постачається з окремого підшляху, тож застосунок без роутера ніколи не тягне `react-router-dom` у свій бандл. `react-router-dom` — необов’язкова peer-залежність.

## Accessibility [#accessibility]

`<Reel>` рендериться як `role="region"` з `aria-roledescription="carousel"`. Задайте пропс `ariaLabel` , щоб дати області назву для екранного читача. Ввічлива жива область оголошує «Слайд N з M» на кожну зміну слайда, не перерендерюючи карусель. Неактивні слайди отримують атрибут `inert` , тож фокус і навігація допоміжних технологій їх пропускають.

`<ReelIndicator>` рендериться як `role="tablist"` з рухомим tabindex на точках; стрілки переміщують фокус, а Enter або Space активує слайд.

Будуєте власне модальне вікно навколо `<Reel>`? `captureFocusForReturn`, `createFocusTrap`, та `getFocusableElements` — вони реекспортовані з `@reelkit/react` для повернення й утримання фокуса.
