---
title: Stories Player для Vue
description: 'Повноекранний Stories Player для Vue: прогрес, жести й темізація.'
---

Повноекранний оверлей плеєра історій у стилі Instagram для Vue: вкладена навігація, таймер автопереходу, зони дотику та налаштовні слоти.

<Callout type="info" title="Скоро">
  Плеєр історій для Vue зараз у розробці. Версія для React уже доступна — [@reelkit/react-stories-player](/docs/stories-player). Версія для Vue матиме ту саму архітектуру й використовуватиме `@reelkit/stories-core` як машину станів, таймер і рендерер прогресу на canvas без прив’язки до фреймворку.
</Callout>
