title: Angular Stories Player
description: Overlay de player de stories para Angular (em desenvolvimento). A versão para React já está disponível; a de Angular vai compartilhar o motor @reelkit/stories-core, com navegação em dois níveis, timer por RAF e progresso em canvas.
---

Player de stories em tela cheia no estilo Instagram para Angular, com navegação aninhada, timer de avanço automático, zonas de toque e slots de template personalizáveis.

<Callout type="info" title="Em breve">
  O stories player para Angular ainda está em desenvolvimento. A versão para React já está disponível em [@reelkit/react-stories-player](/docs/stories-player). A versão para Angular vai seguir a mesma arquitetura, usando `@reelkit/stories-core` para a máquina de estados independente de framework, o timer e o renderizador de progresso em canvas.
</Callout>
