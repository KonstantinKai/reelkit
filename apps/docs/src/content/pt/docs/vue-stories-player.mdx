title: Vue Stories Player
description: Overlay de player de stories para Vue 3 (em desenvolvimento). A versão para React já está disponível; a de Vue vai compartilhar o motor @reelkit/stories-core, com navegação em dois níveis, timer por RAF e progresso em canvas.
---

Player de stories em tela cheia no estilo Instagram para Vue, com navegação aninhada, timer de avanço automático, zonas de toque e slots personalizáveis.

<Callout type="info" title="Em breve">
  O stories player para Vue ainda está em desenvolvimento. A versão para React já está disponível em [@reelkit/react-stories-player](/docs/stories-player). A versão para Vue vai seguir a mesma arquitetura, usando `@reelkit/stories-core` para a máquina de estados independente de framework, o timer e o renderizador de progresso em canvas.
</Callout>
