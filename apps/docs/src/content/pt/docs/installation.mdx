### Comparação com outras bibliotecas [#comparison-with-other-libraries]

O ReelKit mantém **3 slides no DOM** a qualquer momento e dá conta de mais de 10.000 itens. Outras bibliotecas de carrossel renderizam todos os slides, o que trava em listas grandes.

## Peer dependencies [#peer-dependencies]

Os pacotes de framework declaram peer dependencies que provavelmente já estão no seu projeto:

<FrameworkVariant for="react">

### @reelkit/react [#reelkit-react]

- `react` >= 18.0.0
- `react-dom` >= 18.0.0

### @reelkit/react-reel-player [#reelkit-react-reel-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-lightbox [#reelkit-react-lightbox]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

### @reelkit/react-stories-player [#reelkit-react-stories-player]

- `@reelkit/react`
- `react` >= 18.0.0
- `react-dom` >= 18.0.0
- `lucide-react` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="angular">

### @reelkit/angular [#reelkit-angular]

- `@angular/core` >= 17.0.0
- `@angular/common` >= 17.0.0

### @reelkit/angular-reel-player [#reelkit-angular-reel-player]

- `@reelkit/angular`
- `@angular/core` >= 19.0.0
- `lucide-angular` >= 0.460.0

### @reelkit/angular-lightbox [#reelkit-angular-lightbox]

- `@reelkit/angular`
- `@angular/core` >= 17.0.0
- `lucide-angular` >= 0.400.0

</FrameworkVariant>

<FrameworkVariant for="vue">

### @reelkit/vue [#reelkit-vue]

- `vue` >= 3.0.0

</FrameworkVariant>

## TypeScript [#typescript]

Todos os pacotes já vêm com definições de tipo TypeScript. Nenhum pacote @types adicional é necessário.
