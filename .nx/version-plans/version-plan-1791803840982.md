StoriesOverlay and StoriesUrlOverlay take the story type from `groups`: pass your own story type that extends StoryItem and the overlay keeps its fields, while groups of any other shape fail to compile
BREAKING: Requires Vue 3.3 or later. The overlays are generic components, and an older Vue runtime drops their props and events
BREAKING: StoriesOverlayProps and StoriesUrlOverlayProps now describe the props a parent passes, so props with a default are optional: reading `enableKeyboard` from the type gives `boolean | undefined`, not `boolean`
