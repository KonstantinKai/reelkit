New URL-driven mode: pass `urlParam` and the lightbox opens and closes itself from the address bar — shareable links, deep links, and a back button that closes the gallery
Stale or unresolvable parameters are dropped from the URL instead of asserting a slide that cannot open
`urlCodec` / `urlLocator` key links by a stable id so a bookmark survives the gallery being reordered
BREAKING: `urlParam` and `isOpen` are mutually exclusive — pass exactly one
